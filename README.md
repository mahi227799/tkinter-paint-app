# Tkinter Paint App

A simple desktop paint application built with Python and Tkinter. I created this project to practice Python GUI development and working with mouse events, drawing tools, and user interactions.

## Features

- Pencil and eraser tools
- Rectangle and oval drawing
- Adjustable brush size
- Multiple preset colors
- Custom color picker
- Filled or outlined shapes
- Undo functionality
- Clear canvas option
- Export drawings as PostScript files
- Displays cursor position and current tool information

## Getting Started

### Requirements

- Python 3
- Tkinter

Tkinter is included with most standard Python installations, so no additional packages are required.
